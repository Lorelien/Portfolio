Figma Learning New Skills

Figma Learning Skills is my personal practice lab to strengthen my visual and interactive skills in Figma. Here I experiment with the Pen Tool, vector illustrations, line icons and micro-interactions.

I practice with boolean operations, component states and Smart Animate. This collection shows my technical growth in Figma to build my own assets for future UX/UI projects.

Space drawings

In this series I created six space-related illustrations using the same approach: building from basic shapes, working with the Pen Tool and boolean operations (union and subtract). The goal was to gain consistency in my vector style and to build more complex images step by step from simple shapes.

Line icons

This icon set consists of 11 line icons that I drew entirely in Figma. I practiced consistent stroke width, simple shapes and a recognisable style. The goal is to be able to create my own icons for interfaces later, instead of always using existing icon libraries.

Campfire

In this campfire scene I combine everything I’ve learned so far: working with basic shapes, union and subtract, and the Pen Tool for details. The scene is built entirely from vector shapes in Figma. I didn’t use any external illustrations, but built every element myself, from the flames to the logs and the surrounding environment.

Mermaid

With this mermaid illustration, the “Use as mask” function didn’t work as expected. Instead of following the tutorial literally, I looked for my own solution using separate layers, extra shapes and manually adjusted paths.

This exercise taught me not only more about masking in Figma, but also to flexibly search for alternatives when a technique doesn’t work as planned.

Carousel animation

In this experiment I created an interactive “Choose your character” carousel in Figma using Smart Animate and component states. When selecting a character, the card smoothly expands to a highlighted view while the other cards scale along. This exercise gave me more insight into timing, interaction and micro-interactions within interfaces.

Line drawings

I create line drawings in Figma with the Pen Tool to give my portfolio more personality and visual cohesion. I use the illustrations, such as cats and mountains, as decorative elements on different pages. This way I combine my Figma practice with developing my own illustration style.
